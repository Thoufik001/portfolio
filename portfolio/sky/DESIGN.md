# Under the same sky — isolated portfolio experiment

Route: `/sky/`. The other portfolio entry points and their styles are unchanged.

Visual intent: the supplied Hark reference's atmospheric blue-to-horizon skies, sparse navigation, rounded floating windows and lightly translucent surfaces. Portfolio content takes the place of its chat and third-party integration content.

Geist Variable carries all typography. Display 36–56px, headings 24–28px, reading copy 16–17px, controls 14px, index 14px, supporting labels 12px. Day text is #162332 with #344353 secondary; night text is #f6f8fd with #e3e8f1 secondary. Reading sheets use a stable pale background for long-form contrast. Navigation uses pale translucent glass and dark text, with a white selected pill, including against night skies. These sky-specific values are scoped to `.sky-app`.

A procedural Three.js full-screen shader renders the sky with layered noise for visible wind-driven cloud silhouettes and twinkling stars. Local sunrise and sunset determine the phase; cloud cover, precipitation and wind from Open-Meteo affect the atmosphere. The sky is an artistic interpretation, not a physically accurate photograph or camera feed. Weather refreshes every 15 minutes; local time every 30 seconds. Weather failure is explicitly labelled and falls back to a time-based sky. On entry, browser geolocation requests visitor permission. Coordinates are rounded to two decimal places before weather and city-name lookup requests to Open-Meteo and BigDataCloud. Denial or failure keeps local time without claiming a city or weather; manual city selection remains available. Device location is not stored. The Pranshu Agarwal reference informed a pale glass weather panel with city selection, a pointer- and keyboard-operable 24-hour semicircle dial, and weather previews. The weather-app reference contributes the temperature handle, elapsed arc and softly tinted card. Dial previews use today’s hourly forecast and are labelled as forecasts. Previews are labelled and can be reset to live conditions.

Cloud animation can be paused, respects reduced motion, and stops in hidden tabs. Shader colors and weather parameters ease toward new targets with a 240ms damping constant; repeated dial inputs retarget the current transition. The CSS fallback interpolates sky colors over 700ms. Reduced motion updates immediately. No sun or moon is drawn. The render buffer is capped at 1280px width and DPR 1. If WebGL is unavailable, an equivalent CSS sky gradient remains. Fonts, icons and project assets are local/shared; no new dependency was installed.

Project previews use existing public portfolio screenshots or a clearly labelled synthetic reconstruction. Case content is read from the current case-content source without changing it. No invented research, shipped status or metrics. Navigation, project selection and weather settings use semantic native controls. Document scrolling remains normal.
